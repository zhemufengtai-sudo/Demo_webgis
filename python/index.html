SCS降雨-径流模型说明

    

      本demo分为两部分:一是基于OpenGMS平台的模型服务容器，将模型条目库里面SCS降雨-径流关系模型部署到本地，基于Python后端
      与模型服务容器通过json文件传输，基于FastAPI进行前后端传参，并通过chart.js进行可视化展示；
二是基于Leaflet进行地图可视化，内置
      行政区划与公园geojson数据，可通过点击公园geojson数据获取对应S数据，设置不同降雨量，进行可视化分析

      经典SCS降雨-径流关系模型：Q=(P-0.2S)^2/(P+0.8S)是建立方便有效径流预测模型是垄沟集雨种植技术设计和推广的关键。
      通过P(一次降雨的降雨总量)和S(流域当时的最大可能滞留量)可以得到Q(径流量),进而为后续进行评估铺膜材料、田间规格等相关工程参数设置提供辅助建议。
