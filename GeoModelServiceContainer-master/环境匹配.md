## The Writing Rules for SoftWare and HardWare Information
---
### 1. Example
```xml
   <Runtime name="SWATModelAllInOne" version="1.1.0.0" baseDir="$(ModelServicePath)\SWATModelAllInOne" entry="SWATModelAllInOne.exe">
    <HardwareConfigures>
	  <Add key="memory size" value="[0.5G,infinite)" />
	  <Add key="cpu core numble" value="[2, infinite)" />
	  <Add key="disk avail size" value="[50GB,infinite)" />
	  <Add key="cpu frequency" value="[2.2GHz,infinite)" />
    </HardwareConfigures>
    <SoftwareConfigures>
      <Add key="Microsoft Visual C++ 2010" platform="x64" value="10" />
	  <Add key="Operation System" platform="x64" value="win 7||win 8||win 10|| win xp" />
	  <Add key="JAVA SE Development Kit 8" platform="x64" value="8.0" />
    </SoftwareConfigures>
    <Assemblies>
      <Assembly name="GDALRasterMapping.exe" path="$(DataMappingPath)\GDALRasterMapping\" />
      <Assembly name="OGRVectorMapping.exe" path="$(DataMappingPath)\OGRVectorMapping\" />
      <Assembly name="" path="$(Assembly)\OGRVectorMapping\" />
      <Assembly name="TauDEM_Path" path="$(ModelServicePath)\TauDEM5Exe\" />
    </Assemblies>
    <SupportiveResources>
      <Add type="library" name="GDAL" />
      <Add type="runtime" name="MSMPI" />
    </SupportiveResources>
  </Runtime>
```
### 2. Writing Rules
> 硬件和软件所在的节点分别表示为：***HardwareConfigures***, ***SoftwareConfigures***. 
当需要添加详细的软硬件需求时，用Add子节点进行表示。具体规则如下所示：

#### 2.1 Rules
 **Add**节点下的key属性表示环境需求的名字,platform属性表示软件的位数，有“x64”和“x86”两种取值(该值用来识别老版与新版MDL之间区别)，而其value值用来表示具体的需求或者版本号。value的取值语法如下：
 1. 逻辑语法：|| , && , () ;
 2. 版本语法：

Type | Description
---|---
区间 | 例如[v1,v2], (v1,v2),(v1,v2], [v1,v2),其中 0 和infinite表示两个极值
x(X) | 例如1.2.x
! | 例如 !1.2.4
value | 例如 1.2.4 或 v1.2.4

> 备注： 非数字格式的版本匹配，现在只支持完全相等，对其他情况兼容。

#### 2.2 Common Information 

对于硬件环境，目前已有的内容选项有：
1. memory size : 需要的内存；
2. cpu core number: 需要的cpu核数；
3. cpu frequency: cpu 赫兹
4. disk avail size: 需要磁盘多大空间(memory size就够了)
5. cpu model: 需要的cpu类型

对于软件环境，常见的内容选项示例有：
1. Operating System;
2. Java SE Development Kit;
3. Python 3.6.4 Executables(64-bit)
4. MATLAB R2016a;
5. Microsoft Visual c++ 2010 x64 Redistributable
6. MongoDB 3.4.7
7. Microsoft SQL Server 2008 Database Engine Shared
8. Node.js
9. Microsoft Visual C++ 2010 x64 Runtime 
10. Apache Tomact 8.5 Tomact8
